# Context Selection

Start with applicable instructions, the requested outcome, and the selected
task only when tracked. Follow one focused canonical source into relevant code
and tests. Do not load every task, the complete docs tree, or runtime archives.

Keep in context:

- approved scope and acceptance;
- constraints, accepted decisions, and unresolved questions;
- exact paths, interfaces, errors, and verification results needed now.

Summarize consumed investigation when it no longer supports the current step.
Preserve rationale and open objectives, not transcripts or duplicate docs.
Recover truncated evidence from its source before relying on missing details.

Delegate only independent work with a self-contained scope and bounded result.
Synthesize before requesting implementation; do not require multi-agent work
merely because the harness supports it. Costs and compression thresholds depend
on the host, not a universal percentage or claimed performance improvement.

See [handoff](memory-persistence-pattern.md) and
[coordination](multi-agent-pattern.md).
